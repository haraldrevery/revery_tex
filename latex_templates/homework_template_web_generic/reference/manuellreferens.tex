% thebibliography prints its heading as a *starred* section, and starred
% sections are neither numbered nor listed — so without these two lines the
% references are missing from the table of contents.  \phantomsection gives
% hyperref an anchor to jump to, \addcontentsline puts the entry in the TOC,
% and the \label lets you write \cref{References_toc} in the text.
