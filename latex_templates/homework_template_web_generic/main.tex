% WHY THESE FONTS AND NOT Times New Roman / Arial / Courier New
%  Those three are proprietary faces installed by your operating system.  A
%  local TeX Live picks them up from the system font database; the browser
%  engine has no system font database at all — it can only see fonts that are
%  part of the TeX distribution itself.  Naming a system font there does not
%  fall back to something similar, it stops the build.
%
%  TeX Gyre is the way out.  Termes, Heros and Cursor are *metric clones* of
%  Times New Roman, Arial/Helvetica and Courier New: same advance widths, same
%  line breaks, same page count.  A course requirement that says
%  "Times New Roman or Arial, 12pt" is satisfied by them, and side by side the
%  difference is close to invisible.  All are SIL Open Font Licence and all
%  ship with TeX Live, so the same file also builds on your desktop.

% --- ACTIVE: TeX Gyre (Times/Arial/Courier metrics) ----------
\setmainfont{TeX Gyre Termes}       % Times New Roman metrics  — SIL OFL
\setsansfont{TeX Gyre Heros}        % Arial / Helvetica metrics — SIL OFL
\setmonofont{TeX Gyre Cursor}       % Courier New metrics       — SIL OFL
\setmathfont{TeX Gyre Termes Math}  % matching math             — SIL OFL

% bundle, so a document that loads them is desktop-only.  float.sty is

% algorithm float — write the steps inside it however you like (an
